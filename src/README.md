# ARCHIFACT — Devin Development Prompt

Ce dossier contient le prompt maître destiné à Devin pour poursuivre et industrialiser le projet ArchiFact généré avec Google AI Studio.

## Fichier principal

- `PROMPT_DEVIN_ARCHIFACT.md`

## Utilisation

1. Ouvrir le repository ArchiFact dans Devin.
2. Fournir `PROMPT_DEVIN_ARCHIFACT.md` comme instruction de travail.
3. Demander à Devin de commencer par l'audit du repository réel.
4. Ne pas demander une réécriture complète avant l'audit.
5. Vérifier chaque étape avec les tests et le build.

Le prompt impose une migration progressive vers une architecture web full-stack responsive/PWA, avec Gemini, gestion des crédits, GeniusPay, backend, PostgreSQL, tests et CI/CD, tout en préservant le projet existant.
